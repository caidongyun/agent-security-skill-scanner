## 🏗️ 架构演进

### 生成器架构

```
generators/
├── base_generator.py         # 基础类 (250 行)
├── python_generator.py       # Python (250 行)
├── powershell_generator.py   # PowerShell (500 行)
├── javascript_generator.py   # JavaScript (400 行)
├── bash_generator.py         # Bash (300 行)
├── go_generator.py           # Go (600 行)
├── php_generator.py          # PHP (700 行)
├── rust_generator.py         # Rust (500 行)
└── ruby_generator.py         # Ruby (500 行)

总计：~4000 行代码
```

### 统一 CLI

```bash
python3 -m generators.cli --language <lang> --count <n>
```

支持语言：
- python, powershell, javascript, bash
- go, php, rust, ruby

### 质量门禁

```bash
./quality_gate.sh <language> <count> <round>
```

三级门禁：
1. Gate 1: 样本质量 (≥80 分)
2. Gate 2: 规则质量 (≥90 分)
3. Gate 3: 扫描验证 (≥95% 检测率)

### ✅ 做得好的
