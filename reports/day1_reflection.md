## ⚠️ 遇到的问题

### 问题 1: Go 样本编译验证
**现象**: Go 样本需要编译才能执行，解释器无法直接运行  
**影响**: 无法测试运行时行为  
**解决**: 
- 专注于静态代码特征
- 添加编译指导注释
- 后续添加 Docker 编译环境

### 问题 2: PHP 环境依赖
**现象**: PHP 样本需要 Web 环境或 CLI  
**影响**: 部分功能无法在纯文本中验证  
**解决**:
- 区分 CLI 和 Web 模式
- 添加环境检测
- 提供测试指导

### 问题 3: 规则特异性
**现象**: 初期规则过于宽泛  
**影响**: 可能误报正常代码  
**解决**:
- 增加语言特定关键字
- 添加上下文检测
- 多特征组合验证

## 💡 改进建议

### 样本生成优化
1. **增加变体**: 每种攻击类型生成 10+ 变体
2. **代码混淆**: 添加变量重命名、字符串加密
3. **多态性**: 相同功能不同实现
4. **真实场景**: 模拟真实攻击案例

### 规则优化
1. **分级检测**: L1(快速) → L2(深度) → L3(行为)
2. **机器学习**: 训练分类器辅助检测
3. **上下文感知**: 区分开发和攻击代码
4. **动态更新**: 根据漏报/误报调整

### 质量门禁增强
1. **自动化测试**: CI/CD 集成
2. **性能基准**: 扫描速度监控
3. **趋势分析**: 检测率/误报率图表
4. **告警通知**: 质量下降时告警
