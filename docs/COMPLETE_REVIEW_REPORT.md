### 2.1 版本历史

| 版本 | 架构 | 特点 | 状态 |
|------|------|------|------|
| **V1** | 单线程 YARA | 基础扫描 | ❌ 淘汰 |
| **V2** | 意图识别独立 | YARA + 手动意图 | ❌ 淘汰 |
| **V3 Lite** | 并发 YARA | 8 线程优化 | ✅ 稳定 |
| **V3 Hybrid** | YARA 主导 + 意图辅助 | 平衡检测率/误报率 | ✅ 推荐 |
| **V4 分布式** | 分片 + 原子写入 | 67 Worker 并行 | ✅ 大规模 |
| **V5** | **内置意图识别** | **YARA + 意图 自动集成** | ✅ **最新** |

### 2.2 V5 架构详情

```
┌─────────────────────────────────────────┐
│         Scanner V5 (Intent-Aware)       │
└─────────────────────────────────────────┘
              ↓
    ┌─────────────────┐
    │   样本收集器     │
    │  (65K+ 样本)     │
    └────────┬────────┘
             ↓
    ┌─────────────────┐
    │  ThreadPool     │
    │  Executor       │
    │  (8-16 线程)     │
    └────────┬────────┘
             ↓
    ┌─────────────────────────────────┐
    │         扫描流程                 │
    │                                 │
    │  1. YARA 规则匹配                 │
    │     ↓                           │
    │  2. 意图识别分析 (自动)           │
    │     ↓                           │
    │  3. 综合判定 (YARA + 意图)        │
    │     ↓                           │
    │  4. 结果输出                    │
    └─────────────────────────────────┘
             ↓
    ┌─────────────────┐
    │   JSON 报告       │
    │  (含意图分析)    │
    └─────────────────┘
```

### 2.3 核心代码结构

```python
class ScannerV5:
    def __init__(self, rules_dir, workers=8, enable_intent=True):
        self.rules = load_rules(rules_dir)
        self.detector = EnhancedIntentDetector()  # 内置
        self.enable_intent = enable_intent
    
    def scan_sample(self, sample_path, attack_type):
        # 1. YARA 扫描
        yara_matches = self.rules.match(content)
        
        # 2. 意图识别 (自动)
        if yara_matches and self.detector:
            intent = self.detector.analyze(content, yara_matches)
            
            # 3. 综合判定
            if intent.malicious:
                verdict = "malicious"
            elif intent.benign and low_risk:
                verdict = "benign"  # 降低误报
            else:
                verdict = "malicious"
```

## 4. 意图识别效果

### 4.1 工作原理

```
YARA 匹配
   ↓
意图识别器分析
   ↓
┌──────────────────────────┐
│ 恶意意图 → 确认恶意       │
│ 良性意图 + 低风险 → 放过  │
│ 可疑意图 → 看风险分数     │
└──────────────────────────┘
   ↓
最终判定
```

### 4.2 适用场景

**最佳** ✅:
- 传统攻击 (tool_poisoning, credential_theft 等)
- 有明显恶意关键词
- 有明确攻击目标

**待优化** ⚠️:
- AI 特定攻击 (prompt_injection)
- 高度混淆代码 (evasion)
- 边界模糊样本

### 4.3 性能开销

| 模式 | 平均延迟 | P99 延迟 |
|------|---------|---------|
| 仅 YARA | ~2ms | ~6ms |
| YARA + 意图 | ~3ms | ~9ms |
| **开销** | **+1ms** | **+3ms** |

**结论**: 意图识别增加约 50% 延迟，但降低 100% 误报 ✅
