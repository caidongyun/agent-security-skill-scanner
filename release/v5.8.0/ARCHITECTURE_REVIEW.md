## 📋 五、核心代码审查

### 5.1 PatternEngine

**优点**:
- ✅ 预编译正则，性能好
- ✅ 去重逻辑防止重复匹配
- ✅ 返回 max_weight 用于评估

**缺点**:
- ❌ 权重范围过大 (8-60)
- ❌ 无攻击类型优先级
- ❌ 模式硬编码在类中

**建议**:
```python
# 改进：权重标准化 + 外部配置
ATTACK_PATTERNS = load_patterns_from_config()  # 从 YAML 加载
WEIGHT_RANGE = (10, 50)  # 标准化权重范围
```

### 5.2 RuleEngine

**优点**:
- ✅ 支持多规则文件
- ✅ 置信度分级 (critical/high/medium/low)
- ✅ 只编译高置信度规则

**缺点**:
- ❌ 硬编码路径依赖 v5.7.0
- ❌ min_confidence 默认 90 太高
- ❌ 无规则缓存机制

**建议**:
```python
# 改进：相对路径 + 可配置阈值
def __init__(self, rules_file=None, min_confidence=60):
    self.rules_file = rules_file or get_default_rules_path()
    self.min_confidence = min_confidence
```

### 5.3 Scanner

**优点**:
- ✅ 并行双检架构
- ✅ 详细统计信息
- ✅ 异常处理完善

**缺点**:
- ❌ 注释说"快速路径"但实际是并行
- ❌ 无文件大小限制
- ❌ 无编码失败日志

**建议**:
```python
# 改进：添加文件验证
def scan_file(self, file_path: Path) -> ScanResult:
    # 文件大小检查
    if file_path.stat().st_size > MAX_FILE_SIZE:
        return self._skip_file(file_path, "File too large")
    
    # 文件读取
    try:
        content = file_path.read_text(...)
    except Exception as e:
        logger.warning(f"Failed to read {file_path}: {e}")
        return self._skip_file(file_path, str(e))
```
