### 4. 专项规则增强

#### Evasion 检测
- marshal/compile/importlib 动态执行
- lambda/getattr 反射调用
- base64 编码绕过

#### Resource Exhaustion 检测
- Fork 炸弹 (os.fork)
- 内存耗尽 (memory_hog)
- CPU 耗尽 (cpu_hog)
- K8s 特权容器 (hostPID, hostNetwork, privileged)

#### Memory Pollution 检测
- 记忆注入 (memory_injection)
- 虚假记忆 (false_memories)
- 上下文污染 (context_pollution)
- 向量数据库攻击 (vector_store)

#### Tool Poisoning 检测
- GitHub Actions 投毒
- CI/CD pipeline 篡改
- 工作流注入 (run: curl|wget|bash)

#### Data Exfiltration 检测
- K8s 数据外传配置
- 特权容器检测
- HTTP/POST 外传

#### False Prone 检测
- C2 服务器通信
- 系统信息收集伪装
- 隐藏恶意行为
