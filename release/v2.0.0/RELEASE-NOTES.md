## 🆕 新增功能（v2.0.0）

### 误报处理系统

1. **本地白名单**
   - 文件白名单（按路径/哈希）
   - 模式白名单（正则表达式）
   - 规则白名单（按规则 ID）
   - 支持过期时间和作用域

2. **远程分析**
   - LLM 上下文关联分析
   - 置信度评分
   - 自动加白建议

3. **隐私保护**
   - 公共/个人白名单分离
   - 发布前隐私检查
   - 个人配置不提交

4. **官方采集**
   - 自动采集可信技能
   - 建立初始白名单

## ⬆️ 升级指南

### 从 v1.x 升级

```bash
# 1. 备份配置
cp whitelist/local.json whitelist/local.json.bak

# 2. 下载 v2.0.0
cp -r release/v2.0.0/ agent-security-scanner/

# 3. 恢复配置
cp whitelist/local.json.bak agent-security-scanner/whitelist/local.json

# 4. 验证
python3 agent-security-scanner/scanner_cli.py --help
```
