### 方案 1: 权重动态调整

**目标**: AST 权重从 50% 提升至 70%

**实施方案**:
```python
# 综合判定权重优化
def _ensemble_judgment(self, result):
    base_score = result['base_scan']['score']
    ast_score = result['ast_scan']['malicious_score']
    ast_confidence = ast_score / 100  # 归一化
    
    # 动态权重调整
    if ast_confidence >= 0.9:
        ast_weight = 0.8
    elif ast_confidence >= 0.7:
        ast_weight = 0.6
    else:
        ast_weight = 0.4
    
    final_score = base_score * (1 - ast_weight) + ast_score * ast_weight
    
    if final_score >= 50:
        return {'verdict': 'MALICIOUS', 'confidence': final_score}
    elif final_score >= 20:
        return {'verdict': 'SUSPICIOUS', 'confidence': final_score}
    else:
        return {'verdict': 'SAFE', 'confidence': 100 - final_score}
```

**预期效果**:
- 误报数：47 → ≤30（-36%）
- 一致率：90.6% → ≥92%（+1.4%）

**风险**: 权重设置不合理可能导致一致率下降  
**应对**: 网格搜索最优权重，测试验证
