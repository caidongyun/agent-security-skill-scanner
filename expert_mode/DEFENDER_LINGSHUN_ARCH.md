## 🔄 迭代流程

### 核心循环

```
1️⃣ 迭代开发
    ├── 分析样本 → 发现改进点
    └── 修改 Defender 代码

2️⃣ 探索发现
    ├── 样本探索 → 新攻击手法
    ├── 边界测试 → 极端情况
    └── 对抗样本 → 绕过尝试

3️⃣ 自动修复
    ├── 问题定位
    ├── 方案设计
    └── 代码实现

4️⃣ 智能学习
    ├── 经验记录
    ├── 模式识别
    └── 知识沉淀

5️⃣ 并发测试 ⚡
    ├── Runtime 覆盖率测试
    ├── Runtime 准确率测试
    ├── Runtime 延迟测试
    ├── DLP 覆盖率测试
    ├── DLP 准确率测试
    └── DLP 延迟测试

6️⃣ 反思评估
    ├── 需求完整性
    ├── 质量风险
    ├── 技术债务

7️⃣ 质量提升
    ├── 覆盖率优化
    ├── 准确率优化
    └── 性能优化
```

## 📊 质量指标体系

### Runtime 防护

| 指标 | 目标 | 计算方式 |
|------|------|----------|
| 覆盖率 | ≥95% | 检测规则数 / 总攻击手法 |
| 准确率 | ≥99% | 正确拦截 / 总攻击 |
| 误报率 | ≤1% | 误报数 / 总正常行为 |
| 延迟 | ≤10ms | 平均响应时间 |

### DLP 检测

| 指标 | 目标 | 计算方式 |
|------|------|----------|
| 覆盖率 | ≥95% | 规则覆盖类型 / 敏感数据类型 |
| 准确率 | ≥99% | 正确识别 / 总敏感信息 |
| 脱敏率 | 100% | 已脱敏 / 应脱敏 |
| 延迟 | ≤5ms | 平均处理时间 |


## 📈 迭代策略

### 阶段规划

| 阶段 | 轮次 | 重点 | 目标指标 |
|------|------|------|----------|
| V1 | 1-10 | 基础功能 | Runtime + DLP 可用 |
| V2 | 11-30 | 样本积累 | 100+ 测试样本 |
| V3 | 31-50 | 准确率优化 | 95% 准确率 |
| V4 | 51-70 | 性能优化 | <10ms 延迟 |
| V5+ | 71+ | 对抗升级 | 对抗性样本训练 |

### 超越机制

```
每轮评估:
├── 分数 > 上轮 → 保留改进 ✅
├── 分数 ≤ 上轮 → 回滚修改 ❌
└── 分数 = 历史最佳 → 记录里程碑 🏆
```

## 🛠️ 使用方式

### 命令行

```bash
# 运行全部模块
python3 defender_lingshun.py --target all --rounds 100

# 只运行 Runtime
python3 defender_lingshun.py --target runtime --rounds 50

# 只运行 DLP
python3 defender_lingshun.py --target dlp --rounds 50

# 保存结果
python3 defender_lingshun.py --rounds 10 --output results.json
```

### Python API

```python
from defender_lingshun import DefenderLingshun
import asyncio

async def main():
    system = DefenderLingshun(target="all")
    await system.run(rounds=100)
    system.save_results("my_results.json")

asyncio.run(main())
```
