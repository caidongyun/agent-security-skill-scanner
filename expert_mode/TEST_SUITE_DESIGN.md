## 🚀 运行测试

```bash

python3 test_expert.py --suite all

# 运行 Runtime 测试
python3 test_expert.py --suite runtime

# 运行 DLP 测试
python3 test_expert.py --suite dlp

# 运行指定用例
python3 test_expert.py --case RT-01,DLP-01

# 生成报告
python3 test_expert.py --report results.json
```
